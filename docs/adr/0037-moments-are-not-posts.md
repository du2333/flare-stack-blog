# Moments are not Posts

A Moment (动态, as asked in issue #63) is a short, untitled update the Admin posts and manages on the public Moments page, public as soon as it is posted. It is its own concept with its own storage, not a kind of Post with the title hidden. Making it a Post would carry every Post rule along and need an exception for each: unique slugs, drafts and publishing, the Public Content Snapshot, Post Revisions and Unpublished Changes, Category and Tags, the Post Cover, search indexing and Comments, which all belong to a Post. The price is that what a Moment does share with Posts (its feed, sitemap entries, HTTP API and Agent Skill support, Media references) is built for it separately. Readers cannot comment on Moments for now; adding that later means letting a Comment belong to something other than a Post.
