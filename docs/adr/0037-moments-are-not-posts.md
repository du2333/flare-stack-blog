# Moments are not Posts

A Moment (动态, as asked in issue #63) is a short, untitled update the Admin posts and manages on the public Moments page, public as soon as it is posted. It is its own concept with its own storage, not a kind of Post with the title hidden. Making it a Post would carry every Post rule along and need an exception for each: unique slugs, drafts and publishing, the Public Content Snapshot, Post Revisions and Unpublished Changes, Category and Tags, the Post Cover, search indexing and Comments, which all belong to a Post. The price is that what a Moment does share with Posts (its feed, sitemap entries, HTTP API and Agent Skill support, Media references) is built for it separately. Comments are the exception: a Comment belongs to a Post or a Moment, one Comment concept with the same rules for placeholders, muting, notifications, the Admin's reply queue and a User's own comments, rather than a second comment system for Moments. A Moment's Comments are read and written only on its own page, linked as in ADR 0015 (`/moments/<id>?comment=<id>`), and deleting a Moment deletes them, as deleting a Post does.
