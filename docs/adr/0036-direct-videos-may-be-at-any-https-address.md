# Direct Videos may be at any HTTPS address

Besides Bilibili and YouTube, a Video Embed can be a Direct Video: a video file at any HTTPS address, played by the browser's own `<video>` element. Bilibili and YouTube keep their allowlist, because their player is an iframe that runs the other site's script on the page; a `<video>` runs none, Post bodies already show external images, and only Admins and their API Keys write Post bodies. A host allowlist or a single video-host prefix in System Config was considered and rejected: it ties every deployment to one host, and Posts break when the host changes. Direct Videos are not Media because the Worker cannot transcode and video outgrows the R2 free tier, so the file lives wherever the Admin hosts it and the CMS keeps only its address, with no reference protection. Tightening this later would break published Posts that point elsewhere.
