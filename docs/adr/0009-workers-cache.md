# Cache public pages with Workers Caching

Public HTML and site documents are stored by Workers Caching (`cache.enabled` on the `App` entrypoint). The default fetch handler only resolves locale into `ctx.props` and forwards the request, so the same URL can keep Chinese and English copies without putting locale in the path. Invalidation uses `cache.purge` with `Cache-Tag` values from the same `invalidate.*` paths that bump KV **Public Cache**; a failed purge fails the mutation. Purges are scoped to the entrypoint that calls them, so `invalidate.*` always RPC `App.purgeCache` via `ctx.exports.App` instead of purging from a Durable Object or the default fetch handler. Zone purge and the Cache API are not used. Admin reset calls `purgeEverything`.
